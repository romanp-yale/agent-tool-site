Privacy Policy

Agent Tool · last updated 20 September 2026

Agent Tool is a single-user application operated by Roman Parker. It runs on his own computer and connects only to his own Google account. There are no other users and no hosted service.

Google data it accesses, and why

ScopeWhat it is used for
gmail.modify Reading messages so the assistant can answer questions about them, and marking them read, archived or labelled when asked.
gmail.send Sending mail the user has explicitly asked for and confirmed.
calendar Reading the schedule, finding free time, and creating or editing events when asked.
drive Finding and reading files the user refers to, and saving documents the assistant creates.
documents, spreadsheets, presentations Creating and editing Google Docs, Sheets and Slides at the user's request.
tasks Reading and updating the user's task list.
userinfo.email and openid Confirming which account is connected, so the assistant can say which mailbox it is reading.

Where the data goes

Google data is fetched on demand, used to answer the request in front of it, and not retained beyond what that requires.

  • On the user's computer. Conversation history and the assistant's notes are stored in a local database and local files. Nothing is uploaded to a server operated by this application, because there is no such server.
  • To language model providers. To answer a question about an email or a calendar entry, the relevant text is sent to the model that produces the reply: OpenAI for conversation, and Z.ai via OpenRouter for programming tasks. Only the content needed for that request is sent. Providers are configured to zero-data-retention and no-training endpoints where the provider offers them.
  • Nowhere else. Google data is not sold, shared, used for advertising, or used to train any model, and is not sent to analytics.

Speech

Speech recognition and speech synthesis run locally on the user's own machine. Audio is not uploaded anywhere.

Retention and deletion

Local conversation history and notes persist until the user deletes them, which they can do by removing the application's data directory. Access to the Google account can be revoked at any time from Google Account permissions, which immediately and permanently ends this application's access. Stored credentials can also be deleted locally.

Limited Use

Agent Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
